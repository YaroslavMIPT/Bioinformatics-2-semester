# Анализ почвенного метагенома (16S rRNA) в QIIME 2

Проект посвящен анализу динамики бактериального сообщества почвы при химическом загрязнении различной концентрации (контроль `k0`, дозы `k5` и `k25`) на временном интервале до 360 суток (`d3`, `d90`, `d180`, `d360`).

## Структура репозитория
* `main.tex` — исходный код академического отчета в LaTeX со статистическими таблицами.
* `figures/` — векторные (`.pdf`) и растровые (`.png`, 300 dpi) графики:
  * `taxa_barplot` — профили доминирующих типов бактерий (Phylum).
  * `alpha_diversity_boxplots` — боксплоты индексов Шеннона и Faith's PD.
  * `pcoa_bray_curtis` и `pcoa_unweighted_unifrac` — ординация PCoA ($\beta$-разнообразие).
* `plot_results.py`, `plot_taxa.py` — Python-скрипты визуализации с использованием `qiime2`, `scikit-bio`, `seaborn`.
* `qiime2_downstream.sh` — SLURM-скрипт филогенетического анализа, классификации таксонов и расчета метрик разнообразия.

## Основные результаты
* **Качество данных:** DADA2 сохранил в среднем **94.9%** ридов после денойзинга и фильтрации химер.
* **Ядро сообщества:** *Proteobacteria* (39.56%), *Acidobacteriota* (28.82%), *Actinobacteriota* (14.62%).
* **Статистика:**
  * Достоверные различия структуры сообществ по уровням загрязнения (PERMANOVA Bray-Curtis: $\text{pseudo-}F = 7.34, p = 0.001$).
  * Снижение $\alpha$-разнообразия при внесении токсиканта (Kruskal-Wallis по Шеннону: $p = 0.008$ для `k0` vs `k25`).
